# Симулятор Космической Компании 🚀

Консоль + JavaFX игра на **Java 17** — покупай ракеты, нанимай экипаж,
летай на миссии, считай деньги. Заодно это учебный проект по Java Core
для подготовки к собеседованиям QA Automation / SDET.

> Имена в коде — английские (стандарт индустрии), всё остальное — на русском.

## Требования

JDK 17+ и Maven 3.8+. Больше ничего (JUnit и JavaFX подтянутся сами).

## Запуск

```bash
./c              # терминал (Windows: c.bat — или двойной клик)
./u              # графика JavaFX (Windows: u.bat — или двойной клик)
./t              # 80 тестов (то же самое, что mvn clean test)
```

Нативное приложение (двойной клик, без терминала):

```bash
./p              # macOS → target/dist/*.dmg (Windows: p.bat → *.exe)
```

`jpackage` собирает только под текущую ОС. Неподписанный `.dmg` первый раз
открывай правым кликом → «Открыть». Цвета в терминале гаснут сами в пайпах
(`NO_COLOR=1` — принудительно).

## Архитектура: одно ядро — два лица

```
domain / repository / service   ← ядро (без JavaFX!)
   ├── console                   ← терминал
   └── ui                        ← JavaFX (7 FXML + контроллеры + style.css)
```

Оба интерфейса работают поверх одного `GameSession`. Контроллеры и меню
только показывают и спрашивают — все решения в сервисах. Деньги — `BigDecimal`,
id — `UUID`, время — `java.time`.

Экраны графики: Обзор, Ракеты, Сотрудники, Миссии (запуск в фоне через `Task`
поверх `MissionService.launchAsync`), Финансы, Статистика.

## Карта для новичка 🗺️

Читать в таком порядке: `Main` → `Application` → `GameSession` →
`domain/Rocket` → `service/MissionService`. В каждом пакете есть
`package-info.java` с подсказкой, что внутри. Хочешь X — иди в Y:
миссии → `MissionService`, шанс → `ProbabilityCalculator`,
деньги → `FinanceService`, сейвы → `SaveLoadService`, потоки → `launchAsync*`.

## Как устроено обучение

- **[ROADMAP.md](ROADMAP.md)** — 161 уровень с XP, званиями и боссами, код пишешь ты.
- **[LEARNING.md](LEARNING.md)** — теория с ловушками и вопросами с собеседований.
- **[INTERVIEW.md](INTERVIEW.md)** — Top 30 вопросов + Top 10 live-coding для финального добора.
- **`quests/`** — 29 полигонов с TODO и автопроверкой (`./q 13`).
- **Команды в одно слово**: после `./setup` (один раз!) команды `u c t q p`
  работают из любого места без `./`. Подробнее — `setup` расскажет сам.

Правило: сначала сам, потом сверяйся с эталоном (`src/` — рабочий спойлер).

## Как проходить (прочитай один раз)

1. Открой **[ROADMAP.md](ROADMAP.md)** и начни с **LVL 0** — иди строго по порядку.
2. Теория — в [LEARNING.md](LEARNING.md), задание — либо в `quests/` (полигон),
   либо в проекте (уровни с 🛠️ — правишь настоящий симулятор).
3. Уровень засчитан, когда выполнены его ✅ Приёмка: полигон зелёный / `mvn clean test`
   зелёный / ответы в трекере. Только потом — дальше.
4. XP — за закрытые уровни (сумма в трекере ROADMAP), звания — за пороги XP.
5. Застрял — бери Hint 1→2→3 из уровня (минус 10% XP за каждую), решение — минус 50%.
   Подсмотрел — разберись, закрой и напиши сам заново.

## Правило про AI 🤖

AI — отличный ревьюер, но плохой автор твоих навыков. Порядок такой:
1. реши сам; 2. перечитай LEARNING; 3. Hint 1→2→3; 4. документация/Javadoc;
5. и только потом — AI или готовое решение. А AI используй ПОСЛЕ попытки:
попроси разобрать твою ошибку, показать альтернативное решение
или допросить тебя как на собеседовании. Кто генерирует первое решение
нейросетью — тот тренирует нейросеть, а не себя.

## 🧠 Hard Mode (необязательно)

Для повторного прохождения или уверенных: не читать hints, не смотреть
скелеты решений, закрыть предыдущие файлы, решать с чистого метода,
сначала писать — потом запускать, в prediction-задачах отвечать ДО запуска.
Это не вторая версия курса, а способ прохождения: те же задания, ноль костылей.
